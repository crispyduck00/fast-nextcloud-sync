# Security Policy

Fast Nextcloud Sync is an unofficial, experimental fork primarily maintained for personal/family use.

## Reporting a security issue

Please do **not** publish credentials, app passwords, access tokens, private Nextcloud URLs, or sensitive logs in a public issue.

For a suspected security problem in fork-specific code, open a minimal public issue without sensitive details and ask for a private contact channel, or contact the repository owner through GitHub.

If the issue also affects the upstream **Nextcloud Sync** project, please follow the upstream project's security-reporting guidance as well:

https://github.com/siosig/obsidian-nextcloudsync

## Support expectations

There is no guaranteed security-support SLA, response time, or long-term maintenance commitment for this fork.

Keep Nextcloud Versions and normal backups enabled, use Nextcloud app passwords instead of your account password, and update to newer releases when fixes are published.
